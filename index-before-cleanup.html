FAQ

Frequently asked questions

Does WebGuard guarantee that a website is safe?

No. WebGuard provides basic security signals only. A high score does not guarantee that a website is safe or legitimate.

What does HTTPS mean?

HTTPS means the connection to the website is protected using HTTPS. It is useful, but it does not by itself prove that the website is trustworthy.

Can WebGuard detect every phishing website?

No. WebGuard is a basic signal checker and is not a complete phishing detection system.

Is WebGuard free?

The WebGuard project is designed to use free services and free hosting options where practical.

What should I do if WebGuard shows a warning?

Carefully review the website address and avoid entering sensitive information until you are confident that you are visiting the intended site.

Check a website before you trust it.

Review basic signals with WebGuard and make your own informed decision.

WebGuard provides basic security signals for informational purposes only. A WebGuard score is not proof that a website is safe, legitimate, malicious or fraudulent. Always verify website addresses independently before entering sensitive information.

Install WebGuard Extension

Follow these simple steps to install WebGuard in Chrome.

1
Open Chrome Extensions Open a new Chrome tab and enter:
chrome://extensions/
2
Enable Developer Mode Turn on the Developer mode switch from the top-right corner.
3
Click Load unpacked Click Load unpacked and select your WebGuard extension folder.
4
WebGuard is Installed After selecting the folder, WebGuard will appear in your Chrome extensions list.
💡 Note: This version of WebGuard is a local/unpacked extension. Chrome Web Store installation can be added later when the extension is published.
