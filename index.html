FAQ

Frequently Asked Questions

What is WebGuard?

WebGuard is a basic website security signal checker available as a browser extension and web interface.

Does WebGuard guarantee a website is safe?

No. WebGuard provides basic signals only. Its score does not prove that a website is safe or malicious.

What does WebGuard check?

WebGuard can review signals such as HTTPS, URL structure, domain structure, URL length and certain unusual URL patterns.

Is WebGuard free?

The current WebGuard project is being developed as a free basic security-checking tool.
